# Freight Net SARL: website design previews

Three design options for the new Freight Net SARL website, each in English and Arabic.

- [Option A: Signal](https://mbbarakat.github.io/freightnet-preview/signal/)
- [Option B: Riviera](https://mbbarakat.github.io/freightnet-preview/riviera/)
- [Option C: Clay](https://mbbarakat.github.io/freightnet-preview/clay/)

These are previews, not the finished site: the contact forms do not send messages.

Built from the design files with a small runtime (`vendor/dc-lite.js`) on React 18 (MIT licence, `vendor/REACT-LICENSE.txt`).
